# ✦ ARCAnum — AI Tarot, честная колода Уэйта

Статическое веб-приложение для GitHub Pages. **Без регистрации, без сборки и без обязательных платных API.**

## Что готово

- Все 78 карт Rider–Waite–Smith; прямое и перевёрнутое положение.
- Действительно случайный выбор: браузерный `crypto.getRandomValues`, Fisher–Yates, без повторов.
- Расклады на 1, 3, 5 и 7 карт; темы: отношения, деньги, карьера, выбор, общее.
- Автоматический AI-разбор сразу после открытия карт: прямой ответ, связь карт, роль каждого аркана и практический вывод. Если AI недоступен — краткая базовая трактовка.
- Дневник в LocalStorage (до 50 раскладов) с сохранением выпавших карт и готового AI-разбора, копирование результата.
- Защищённый API Groq через Cloudflare Worker; JSON Schema для структурированных ответов без сырой Markdown-разметки.

## Как открыть локально

Просто открой каталог через локальный HTTP-сервер:

```bash
python -m http.server 8000
```

Затем перейди на `http://localhost:8000`.

> Модули JavaScript (`type="module"`) могут не работать, если открыть `index.html` напрямую как `file://`.

## GitHub Pages — публикация без установки новых версий

1. Создай **публичный** репозиторий `arcanum-tarot` в GitHub.
2. Добавь файлы из этого каталога **в корень репозитория** (включая `index.html`).
3. Открой `Settings → Pages → Build and deployment`.
4. Выбери `Deploy from a branch`, ветку `main`, папку `/(root)`, затем `Save`.
5. Адрес будет `https://USERNAME.github.io/arcanum-tarot/`.

Любой следующий push в `main` автоматически обновляет сайт. Переустанавливать приложение не нужно.

## Почему LLM не встроена напрямую в GitHub Pages

GitHub Pages — статический хостинг. Ключ Groq/Gemini, встроенный в публичный HTML/JS, немедленно станет доступен всем посетителям. Поэтому приложение запускает AI только через **серверный прокси** в `worker/`. Если пароль не настроен или сервис недоступен, отображается базовый разбор без второго дублирующего ответа.

### Подключение Groq + Cloudflare Worker

1. Создай бесплатные аккаунты Groq и Cloudflare (при наличии свободных лимитов).
2. В каталоге `worker/` исправь `ALLOWED_ORIGIN` в `wrangler.jsonc` на `https://USERNAME.github.io` (только origin, без пути репозитория).
3. Выполни `npx wrangler login`, затем `npx wrangler deploy`.
4. Выполни `npx wrangler secret put GROQ_API_KEY` и безопасно введи ключ, когда CLI попросит. **Не добавляй ключ в файл или GitHub.**
5. Придумай случайный секрет от 24 символов. Выполни `npx wrangler secret put ACCESS_TOKEN` и введи его. Это отдельный пароль доступа к AI, не Groq API key.
6. Скопируй адрес вида `https://arcanum-tarot-ai.<subdomain>.workers.dev`.
7. Открой сайт → ⚙ Настройки → вставь адрес Worker (в нашем проекте он уже указан по умолчанию) и пароль из шага 5 → Сохранить. При открытии карт AI-разбор запускается автоматически. Пароль хранится в sessionStorage только этой вкладки.

Модель по умолчанию — `openai/gpt-oss-20b` со строгим JSON Schema-ответом. Настраивается переменной `GROQ_MODEL` на стороне Worker. При использовании другой модели сработает менее строгий JSON-режим. Лимиты бесплатных запросов у Groq могут изменяться; при их исчерпании базовое приложение продолжит работать.

**Защита:** ограничение `Origin` не является аутентификацией. Worker дополнительно требует секрет `ACCESS_TOKEN`, который не публикуется в исходниках; браузер отправляет его в `X-Arcanum-Access`. Это подходит для личного pet-проекта с сильным закрытым паролем, но для массового публичного сервиса потребуются Turnstile и серверные лимиты. Веб-сайт уже полнофункционален без него.

## Приватность

- История раскладов и полученные AI-трактовки хранятся только в LocalStorage этого браузера.
- Изображения карт запрашиваются по HTTPS из публичного репозитория `sixseeds/tarot-api` через `raw.githubusercontent.com` с резервом `cdn.jsdelivr.net`; шрифты — у Google Fonts. Это означает сетевые запросы к указанным поставщикам. При недоступности изображений отображаются карточки-заглушки.
- После настройки AI вопросы и выпавшие карты отправляются на указанный тобой API-прокси и далее Groq. Пароль AI хранится в sessionStorage и не подставляется в публичный код.
- Таро не позволяет удостовериться в чужих мыслях и не гарантирует будущих событий.

## Источники колоды и изображения

Художник: **Pamela Colman Smith**, иллюстрации для **Rider–Waite–Smith Tarot** (1909, public domain в США и большинстве юрисдикций). Ссылки на изображения используются из открытого проекта [sixseeds/tarot-api](https://github.com/sixseeds/tarot-api); сами JPG запрашиваются с `raw.githubusercontent.com/sixseeds/tarot-api/...`, резерв — jsDelivr. Учитывай права на сканы/переиздания при коммерческом использовании.

Значения карт и структура приложения написаны специально для этого проекта. Расклад — инструмент рефлексии, не научный метод предсказаний.
