# ✦ ARCAnum — AI Tarot, честная колода Уэйта

Статическое веб-приложение для GitHub Pages. **Без регистрации, без сборки и без обязательных платных API.**

## Что готово

- Все 78 карт Rider–Waite–Smith; прямое и перевёрнутое положение.
- Действительно случайный выбор: браузерный `crypto.getRandomValues`, Fisher–Yates, без повторов.
- Расклады на 1, 3, 5 и 7 карт; темы: отношения, деньги, карьера, выбор, общее.
- База индивидуальных значений 78 карт и синтез по мастям/старшим арканам/перевёрнутым картам.
- Дневник в LocalStorage (до 50 раскладов), копирование результата.
- Необязательный глубокий AI-разбор через отдельный Cloudflare Worker + бесплатный Groq API.

## Как открыть локально

Просто открой каталог через локальный HTTP-сервер:

```bash
python -m http.server 8000
```

Затем перейди на `http://localhost:8000`.

> Модули JavaScript (`type="module"`) могут не работать, если открыть `index.html` напрямую как `file://`.

## GitHub Pages — публикация без установки новых версий

1. Создай **публичный** репозиторий `arcanum-tarot` в GitHub.
2. Добавь файлы из этого каталога **в корень репозитория** (включая `index.html`).
3. Открой `Settings → Pages → Build and deployment`.
4. Выбери `Deploy from a branch`, ветку `main`, папку `/(root)`, затем `Save`.
5. Адрес будет `https://USERNAME.github.io/arcanum-tarot/`.

Любой следующий push в `main` автоматически обновляет сайт. Переустанавливать приложение не нужно.

## Почему LLM не встроена напрямую в GitHub Pages

GitHub Pages — статический хостинг. Ключ Groq/Gemini, встроенный в публичный HTML/JS, немедленно станет доступен всем посетителям. Поэтому приложение по умолчанию использует собственную базу трактовок, а облачный AI — только через **серверный прокси**, пример в `worker/`.

### Необязательное подключение Groq + Cloudflare Worker

1. Создай бесплатные аккаунты Groq и Cloudflare (при наличии свободных лимитов).
2. В каталоге `worker/` исправь `ALLOWED_ORIGIN` в `wrangler.jsonc` на `https://USERNAME.github.io` (только origin, без пути репозитория).
3. Выполни `npx wrangler login`, затем `npx wrangler deploy`.
4. Выполни `npx wrangler secret put GROQ_API_KEY` и безопасно введи ключ, когда CLI попросит. **Не добавляй ключ в файл или GitHub.**
5. Скопируй адрес вида `https://arcanum-tarot-ai.<subdomain>.workers.dev`.
6. Открой сайт → ⚙ Настройки → вставь адрес Worker → Сохранить. Нажми «Глубокий разбор».

Модель по умолчанию — `openai/gpt-oss-20b`. Настраивается переменной `GROQ_MODEL` на стороне Worker. Лимиты бесплатных запросов у Groq могут изменяться; при их исчерпании базовое приложение продолжит работать.

**Важно для публичного сайта:** ограничение `Origin` полезно для браузерного CORS, но **не служит аутентификацией**. Посторонние клиенты способны подделывать заголовок Origin и исчерпывать бесплатные квоты. Перед публичным запуском AI-прокси обязательно добавь настоящую защиту (например, Cloudflare Turnstile + проверку токена и лимит запросов на сервере). Держать Worker выключенным до этого — безопаснее. Веб-сайт уже полнофункционален без него.

## Приватность

- История раскладов хранится только в LocalStorage этого браузера.
- Изображения карт запрашиваются по HTTPS у внешнего хостинга `petaloverflow.github.io`; шрифты — у Google Fonts. Это означает сетевые запросы к указанным поставщикам. При недоступности изображений отображаются карточки-заглушки.
- После настройки AI вопросы и выпавшие карты отправляются на указанный тобой API-прокси и далее Groq.
- Таро не позволяет удостовериться в чужих мыслях и не гарантирует будущих событий.

## Источники колоды и изображения

Художник: **Pamela Colman Smith**, иллюстрации для **Rider–Waite–Smith Tarot** (1909, public domain в США и большинстве юрисдикций). Ссылки на изображения используются из открытого проекта [sixseeds/tarot-api](https://github.com/sixseeds/tarot-api); сами JPG предоставляются по URL `petaloverflow.github.io/tarot-api/cards/...`. Учитывай права на сканы/переиздания при коммерческом использовании.

Значения карт и структура приложения написаны специально для этого проекта. Расклад — инструмент рефлексии, не научный метод предсказаний.
